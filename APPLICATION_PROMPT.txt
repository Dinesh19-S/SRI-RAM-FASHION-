--------------------------------------------------------------------------------
                            APPLICATION OVERVIEW
--------------------------------------------------------------------------------

Sri Ram Fashions is a comprehensive Business Management System built for textile 
retail businesses. It is a full-stack web application designed to digitize and 
automate daily business operations including billing, inventory management, 
sales and purchase tracking, GST compliance, payment management, and 
comprehensive reporting.

Project Type: Full-Stack Web Application
Domain: Retail and Textile Business Management
Technology Stack: MERN (MongoDB, Express.js, React.js, Node.js)

Target Users:
- Business Owner/Admin: Full access to all features
- Staff Members: Access to billing, inventory, and basic operations
- Auditors: Access to audit-specific reports

--------------------------------------------------------------------------------
                           APPLICATION ARCHITECTURE
--------------------------------------------------------------------------------

The application follows a 3-tier architecture:

1. PRESENTATION LAYER (Frontend)
   - Technology: React.js 18 with Vite build tool
   - State Management: Redux Toolkit
   - Routing: React Router v6
   - UI Components: Custom components with Lucide icons
   - Animations: Framer Motion for page transitions
   - Charts: Recharts for data visualization
   - Styling: Custom CSS with glassmorphism design

2. BUSINESS LOGIC LAYER (Backend)
   - Technology: Express.js with Node.js
   - Authentication: JWT (JSON Web Tokens)
   - API Type: RESTful API
   - Middleware: CORS, Error Handling, Authentication

3. DATA ACCESS LAYER (Database)
   - Database: MongoDB Atlas (Cloud)
   - ODM: Mongoose
   - Collections: Users, Products, Bills, Customers, Suppliers, 
                  SalesEntries, PurchaseEntries, Payments, Categories, Settings

5. BILLING PAGE (BillingPage.jsx)
   
   Location: /dashboard/billing
   
   Purpose: Create GST-compliant invoices for customer sales with automatic 
   calculations and professional A4 print output.
   
   Layout Description:
   - Two-column layout on desktop
   - Left column (wider): Bill form
   - Right column: Bill preview
   
   Components:
   
   A. Page Header:
      - "Create New Bill" title
      - Bill number display (auto-generated)
      - Date picker
   
   B. Customer Details Section:
      - Customer search/select dropdown
        * Search existing customers by name
        * Option to add new customer inline
      - Customer Name field
      - Phone Number field
      - GSTIN field (optional)
      - Address field (textarea)
      - State dropdown (all Indian states)
      - State Code (auto-filled based on state)
      - Place of Supply field
   
   C. Transport Details Section:
      - Transport company name
      - From location
      - To location
      - Number of Bundles
      - Total Packs
   
   D. Product Items Table:
      Headers:
      - S.No (Serial Number)
      - Product (searchable dropdown)
      - Sizes/Pieces
      - Rate Per Piece
      - Pcs in Pack
      - Rate Per Pack (auto-calculated)
      - No Of Packs
      - Amount Rs (auto-calculated)
      
      Features:
      - Add new row button
      - Delete row button for each row
      - Auto-calculate amounts as values change
      - Product dropdown shows available products
      - Auto-fill product details on selection
   
   E. Totals Section:
      - Subtotal (sum of all item amounts)
      - Discount field (optional)
      - Taxable Amount
      - CGST (for intrastate)
      - SGST (for intrastate)
      - IGST (for interstate)
      - Round Off adjustment
      - Grand Total
      - Amount in Words
   
   F. Action Buttons:
      - Cancel button
      - Save as Draft button
      - Generate Invoice button
      - Print Preview button
   
   G. Bill Preview Panel:
      - Live preview of the invoice
      - Updates as form is filled
      - Shows formatted A4 layout
      - Includes company letterhead
      - Customer details
      - Item table
      - Totals and GST breakdown
      - Terms and conditions
      - Signature area
   
   Calculations:
   - Rate Per Pack = Rate Per Piece x Pcs in Pack
   - Item Amount = Rate Per Pack x No Of Packs
   - Subtotal = Sum of all item amounts
   - Taxable Amount = Subtotal - Discount
   - If customer state = company state:
     * CGST = Taxable Amount x (GST Rate / 2) / 100
     * SGST = Taxable Amount x (GST Rate / 2) / 100
   - If customer state != company state:
     * IGST = Taxable Amount x GST Rate / 100
   - Grand Total = Taxable Amount + Total Tax + Round Off
